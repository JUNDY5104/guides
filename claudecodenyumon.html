AI社員が働く会社を、あなたのパソコンで。

CHAPTER 01 / 知る

Claude Codeとは

「答えるAI」から「動くAI」へ

チャットAIに質問すると、返ってくるのは文章です。Claude Codeが返すのは作業の結果。 コードベースを読み・ファイルを編集し・コマンドを実行し・開発ツールと連携する「エージェント型」のAIです。 答えを教える相手ではなく、実際に手を動かす相棒と考えると近いです。

チャットAI
答えを文章で返す
Claude Code
読む・書き換える・実行して結果を返す
🔍 読む (read) ✏️ 書き換える (edit) ▶️ 実行する (run)

※ターミナル＝黒い画面。本書（原典）では使いません。出典：Claude Code公式ドキュメント Overview

日本語で頼むと、仕事が返ってくる

あなたが「先週の会議メモを1枚にまとめて」と日本語で頼む——たったこれだけで、Claude Codeは動きはじめます。 フォルダの中の資料を自分で読み、要点を拾って下書きを作り、ファイルを変える前には「この内容でいいですか」と許可を求めてきます。 手を動かすのはAI、決めるのはあなた。

1

3

4
変える前に許可を求める
5
あなたが確認して完成
特別な操作はゼロ。日本語のお願い、ひとつだけ。

考えて、動いて、確かめる（エージェントループ）

Claude Codeはタスクを受け取ると「状況把握 → 行動 → 検証」の輪を回し、必要なら自分でやり直しながらゴールへ近づきます。 あなたはこの輪の外にいる監督役で、Escキーでいつでも止めて方向を直せます。

コードだけじゃない

Claude Codeはコード専用ではありません。公式も「コマンドラインでできることなら何でも手伝える——文書作成、ビルド、ファイル検索、調べもの」と明言します。 Anthropic社内では法務やマーケなど非エンジニアのチームが日々活用中。プログラミングの知識より、 やりたいことを言葉にできることのほうが大切です。

こわす心配を、設計で消す

「勝手に壊されたら怖い」——最初に多くの人が感じる不安です。Claude Codeはそこを設計で守ります。 このルールを守らせているのはAIではなくアプリ本体。AIのお行儀に頼らない仕組みです。

不安 守り方
勝手に壊されそう変更は許可制（Manual・差分を見てAccept/Reject）
元に戻せるか不安編集は元に戻せる（Escを2回で巻き戻し）
ルールをAIが破りそう許可はAI任せでなくアプリ本体が強制
PC全体を覗かれそう対象は起動時に選んだフォルダの中だけ

出典：Claude Code公式ドキュメント Permissions／How Claude Code works

CHAPTER 02 / わかる

スキルとAI社員

中身は"手順書"入りのフォルダ

スキルとは、SKILL.mdという一枚の"手順書"を入り口にした、ただのフォルダです。 中に指示・参照資料・スクリプトをまとめて置くと、Claudeがそれを自分の道具箱に加えます。特別な設定は要りません—— "いつ使うか"を書いた説明文さえあれば動き出します。

SKILL.md
入り口の手順書 + 参照資料 + スクリプト = ひとつのフォルダ

スキルは2025年10月にAnthropicが公式化した仕組みです。出典：Claude Code公式ドキュメント「スキル」

覚えさせず、本棚に置く

スキルは中身を"覚えさせる"のではなく、本棚に"置く"仕組みです。ふだんClaudeが見ているのは背表紙、つまり名前と短い説明だけ。 あなたの頼みごとがその説明に合ったときはじめて、棚から抜き出して手順書の中身を読みます。だから何十個入れても、使うまでの負担はほぼゼロです。

1
レベル1：名前と説明だけを見ている（約100トークン）
2
レベル2：依頼が説明に合った時だけ、手順書の本文を読む（5,000トークン未満が目安）
3
レベル3：参照資料やスクリプトは、必要になった時だけ開く・動かす

段階的開示：関連する内容だけが、その時々の"作業机"に載る（公式）。

作るのは一度きり

スキルの利点は大きく三つ。ひとつの仕事の専門家に仕立てられること、一度作れば毎回教え直さなくても自動で再利用されること、 複数を積み重ねて長い作業も組み立てられること。さらに"どこに置くか"で"誰に届くか"が決まります。

置き場所 届く範囲
自分だけ（~/.claude/skills）自分のみ
チームで共有（.claude/skills・gitに載せる）チーム全員
組織全体（管理者が展開）組織のメンバー全員

プロンプトとの違い：プロンプトは1回の会話向け。スキルは何度もの会話にわたって同じ手順を渡せる。

並列で働く専門AI（サブエージェント）

サブエージェントは、特定の仕事を任せられる"専門のAIアシスタント"です。一人ずつ専用の作業机（コンテキスト）と、 使ってよい道具・権限を持ち、任された仕事だけをこなして結果の要約だけを返します。互いに独立しているので、複数を同時に走らせて手分けもできます。

🔍
調べる担当
✍️
書く担当
✅
確かめる担当

3レーンが専用の机・限られた道具・独立した権限で同時進行し、あなた（メイン会話）には要約だけが返る——一本の流れではなく"横並び"です。

✓ 本会話を汚さず調べ物を任せる ✓ 道具を絞って"読むだけ"の担当を作る ✓ 速く安いモデルに回して費用を抑える

使い分け：スキル＝知識と手順の再利用、サブエージェント＝作業そのものの分離・委譲（公式）。出典：Claude Code公式ドキュメント「サブエージェント」

任せている間、あなたは"監督"でいい

仕事を任せても、丸投げして放置、にはなりません。あなたの役割が、手を動かす人から"監督"に変わるだけです。 ファイルを書き換える前には、必ず変更案（差分）を見せて許可を求めてきて、あなたが「はい」と言うまで勝手には確定しません。

👁️
① 作業中
いま何をしているかを表示し、終わると要約で報告
🚦
② 確認ゲート
変える前に差分を見せ、あなたの許可を待つ
⏹️
③ 停止
Escキーでいつでも中断できる

CHAPTER 03 / 始める

はじめ方

使うのは3つのうち1つのタブ

Claude Codeは、黒い画面（ターミナル）を触らなくても、パソコンのデスクトップアプリから始められます。 アプリには三つのタブがあり、自分のフォルダを直接あつかって作業するのは『Code』タブです。

タブ はたらき
💬 Chatファイルにさわらない通常の会話（claude.aiと同じ）
☁️ Coworkクラウド上でおまかせ長時間作業
📁 Code ← ここを使う自分のフォルダを直接あつかう

事前準備はいりません。Node.jsやコマンドの用意は不要で、アプリにClaude Codeがそのまま入っています。

3ステップで入れる

インストールは大きく三ステップ。公式ページから自分のパソコン用のアプリを取ってきて、開いて起動し、サインインするだけです（2026年7月時点）。

1
claude.com/download で自分のOS用を入手して開く（実行）
2
起動して、claude.aiと同じアカウントでサインイン
3
上部中央の『Code』タブを開く

動作環境（2026年7月時点）：macOS 11以上／Windows 10以上。WindowsはGit for Windowsが必要です。

まずはPro、それで十分

Claude Code（Codeタブ）は無料プランでは使えません。使うには有料プランが必要で、いちばん手軽な入口は 月額$20のPro（2026年7月時点・税別）です。

価格は米ドル・2026年7月時点・税別。日本は消費税10%が上乗せ。最新は公式のプラン一覧で確認してください。

5歩で最初の指示まで

アプリが入ったら、Codeタブで最初のセッションを始めます。まずは、よく知っている小さなフォルダから。

1
実行環境で「Local」を選ぶ（自分のPCで直接あつかう）
2
『Select folder』で対象のフォルダを選ぶ
3
送信ボタン隣で使うモデルを選ぶ（途中で変更可）
4
やってほしいことを日本語で入力
5
Enterで送信

変えるかどうかは、あなたが決める（権限モード）

Claude Codeは、はじめは「Manual（毎回確認）」で動きます。ファイルを変える前に、 どこをどう変えるかを差分（diff）で見せ、あなたがAcceptするまで実際には変更しません。

モード ふるまい
✓ Manual（毎回確認）新しい人におすすめ。変更前に必ず聞く
Accept editsファイル編集は自動でOK（慣れてから）
Plan編集せず、計画だけを提案

公式のすすめ：まずはManualで様子見、慣れたらAccept editsやPlanへ。※上級者向けにAuto／Bypassもあり

よくある質問

はじめる前の6つの不安に答えます。

英語ができないと無理？ ＋

指示は日本語で大丈夫。画面のボタン名（Code・Localなど）は英語ですが、実物の名前のまま案内しています。

パソコンを壊さない？ ＋

変更は許可制。変える前に必ず差分（diff）で見せ、あなたがAcceptするまで実際には変わりません。すべての編集は元に戻せます。

料金は？ ＋

無料プランでは使えません。月額$20のPro（2026年7月時点・税別）から。最新は公式のプラン一覧で確認を。

MacでもWindowsでも？ ＋

両対応（macOS 11以上／Windows 10以上・2026年7月時点）。WindowsはGit for Windowsを一度だけ入れる必要があります。

コードが書けないけど使える？ ＋

書けなくて大丈夫。公式も文書作成やリサーチなどコーディング以外の用途を明記し、Anthropic社内でも法務やマーケの非エンジニアが使っています。

スマホでできる？ ＋

デスクトップアプリはパソコン向け。ただしWeb版（claude.ai/code）で始めた作業は、Claudeのスマホアプリから進み具合を見守れます。

用語ミニ辞典

この本に出た言葉を、ひとことで。

言葉 ひとことで言うと
ターミナル文字で命令する黒い画面。本書のデスクトップアプリでは使わない。
デスクトップアプリパソコンに入れて使うClaudeの入口。ターミナルなしでClaude Codeを動かせる。
Codeタブアプリの中で自分のフォルダを直接あつかうタブ。Claude Codeを使う場所。
プロジェクト（フォルダ）Claudeに作業してもらう対象のフォルダ。まずはよく知っている1つから。
スキルよく使う手順をまとめた手順書（SKILL.md入りのフォルダ）。同じ指示の貼り直しをなくす。
サブエージェント役割を持った専門のAIアシスタント。仕事を任せると並列で働き、結果の要約を返す。
差分（diff）ファイルを変える前に表示される「変更前後のちがい」。許可（Accept/Reject）の判断材料。
権限モードAIにどこまで任せるかの設定。既定はManual（変更前に毎回確認）。
usage ring（使用量リング）残りの使える量をひと目で確認できる表示。
プラン使うために必要な契約。無料では使えず、月額$20のPro（2026年7月時点・税別）から。
