Claude Code デスクトップアプリ
かんたんご利用説明書

〜 黒い画面を使わない、知識ゼロからのAIファイル操作ガイド 〜

この説明書では、パソコンの難しい操作や専門知識（コードの知識など）が一切ない方でも、いつものAIチャットと同じ感覚で安全に「Claude Code」を使いこなすための手順を優しく解説します。

1. Claude Codeってなに？

普段お使いのAIチャット（ChatGPTやGeminiなど）と同じように、日本語で「このファイル直しておいて」と頼むだけで、あなたの代わりにパソコン内のファイルを直接書き換えてくれる非常に賢いアシスタントツールです。

最大の特徴は、エンジニアが使うような「黒い画面（ターミナル）」を一切触らなくてよい点です。普通のアプリと同じようにマウス操作とチャットだけで動かすことができます。

2. 準備編：最初の設定

アプリを開いてログインするだけ

インストールされた「Claude Code」のアイコンをダブルクリックしてアプリを起動します。

画面に表示される「Sign in（サインイン）」と書かれたボタンを押すと、自動的にいつものインターネットブラウザ（Google Chromeなど）が開きます。画面の指示に従ってログインを完了させるだけで準備は完了です。

3. 基本編：かんたん3手順

実際の使い方は、以下のたったの3ステップです。

手順 1：フォルダを選ぶ
画面にある「フォルダを開く」ボタンを押し、AIに作業（修正や確認）をしてほしいファイルが入っているフォルダを選択します。

手順 2：AIにお願いする（チャット入力）
画面の下部にあるチャット欄に、日本語でやりたいことを入力して送信します。

手順 3：確認してOK（適用）ボタンを押す
AIが「このようにファイルを直しました」と画面に提案を表示します。内容に問題がなければ、確定（Accept/Apply）ボタンを押すだけで実際のファイルが書き換わります。

💡 初めての方への安心アドバイス
AIがあなたの許可なく勝手にファイルを書き換えたり、パソコンを壊したりすることはありません。必ずあなたの「OK」のボタン操作を待ってから動きますので、どうぞ安心して指示を出してください。

4. 画面に「英語の怖いメッセージ」が出てきたら？

作業を進めていると、画面に英語のポップアップメッセージが表示されて進行が止まることがあります。「ウイルスかもしれない」「壊してしまったかも」と怖くなる必要はまったくありません。

これはAIが、「あなたのパソコンの大事なファイルを変更しようとしていますが、本当にこのまま進めてもいいですか？」と、セキュリティのために親切に確認を求めてきている状態です。

ご自身が依頼した作業の途中でこの画面が出た場合は、迷わず「Allow（許可）」や「Yes」、または青く強調されているボタンを押して進めてしまって大丈夫です。

💡 どうしても怖くてボタンが押せないときは？
その表示されている画面をスマートフォンで撮影するか、スクリーンショット（画面キャプチャ）を撮って、使い慣れているChatGPTやGeminiに「この画面が出たんだけど、進めて大丈夫？」とそのまま貼り付けて聞いてみてください。「大丈夫な画面ですよ」と優しく背中を押してくれます。

5. 必殺技：別のAIに「指示書」を作ってもらう方法

Claude Codeのチャット欄を目の前にして、「なんて指示すれば上手く伝わるだろう…」と言葉に詰まってしまうのは当然のことです。そんなときは、あなたが一番使い慣れているChatGPTやGeminiを「通訳」として間に挟むのが一番確実で賢い方法です。

具体的なコピペ手順

ステップ 1：使い慣れたAIに「普通の言葉」で相談する
ChatGPTやGeminiを開き、以下のように普段の言葉で話しかけます。

【コピーして使える魔法の相談文】 〇〇というフォルダの中にあるファイル（例：テキストファイルやHTMLファイルなど）を、〇〇のように書き換えたいです。 Claude CodeというAIツールに指示を出したいので、以下のチャット欄にそのままコピー＆ペーストして使える「正確な指示文」を日本語で作成してください。

ステップ 2：作成された指示文をコピーして貼り付ける
相談したAIが作ってくれた丁寧な指示の文章をそのままコピーし、Claude Codeのチャット欄に貼り付けて実行します。これだけで完璧に意図が伝わります。

ステップ 3：結果やエラーが出たら、またスクショで相談する
もしClaude Codeが思った通りに動かなかったり、よく分からない英語のメッセージを出して止まった場合は、その画面のスクリーンショットを撮り、再びChatGPTやGeminiに貼り付けて以下のように相談してください。

Claude Codeに指示を出したら、このような画面になってしまいました。 次は何て言えば正しく直してくれますか？返信用の指示文を作ってください。

この「使い慣れたAIに相談しながらコピペで進める」やり方なら、専門知識はゼロのままで、まるでベテランエンジニアがついているかのような安心感で作業を進めることができます。
