ツール概要

OVERVIEW

CrossはFX駆け込み寺のX（旧Twitter）アカウント運用を支援するWebアプリです。GASとGemini APIを組み合わせて構築されており、キャラクター別の投稿文生成とチャート解説の自動生成ができます。

このガイドの対象 Crossを実際に操作するスタッフの方向けの使い方マニュアルです。APIキーの設定方法・各モードの操作手順・トラブル対応をまとめています。

主な機能

機能 内容
TEXTモード ジャンル・トーン・メモを指定して、キャラクター別にX投稿文を生成（140字 / 800字）
CHARTモード FXチャートの画像をアップロードすると、初心者向けの解説文を自動生成
IMAGE PROMPT 生成した投稿文をもとに、画像生成AI用のプロンプトを英語で自動作成（TEXTモードのみ）
ログ保存 生成のたびにGoogleスプレッドシートへ自動記録

APIキーの取得と設定

API KEY

CrossはGemini APIを使って文章を生成します。利用するにはAPIキーをアプリに登録する必要があります。

APIキーの取り扱いに注意 APIキーは他人に見せないでください。SNS・メール・チャットに貼り付けたり、公開の場に書いたりしないこと。漏洩すると第三者に無断利用されます。

APIキーの取得手順

  • 1
    Google AI Studio にアクセス
    ブラウザで aistudio.google.com を開き、Googleアカウントでログインします。
  • 2
    「Get API key」をクリック
    左メニューの「Get API key」→「APIキーを作成」をクリックします。
  • 3
    プロジェクトを選択
    有料プランを設定済みのGoogle Cloudプロジェクトを選択します（有料化の手順は次のセクションを参照）。
  • 4
    キーをコピーして保存
    作成されたAPIキーをコピーします。このキーは一度しか表示されないため、安全な場所（メモアプリやパスワード管理ツール）に保存してください。

Gemini有料プランへの切り替え

重要設定
無料プランのままだとエラーが頻発します Gemini APIの無料プランは1分あたりのリクエスト数が非常に少なく、複数人で利用したり続けて使うと「503エラー」「429エラー」が頻発します。安定して使うには有料プランへの切り替えが必要です。
このツールの使用量（1日数十回程度）であれば、月額数百円程度の費用で収まります。

無料プランと有料プランの違い

項目 無料プラン 有料プラン
1分あたりの上限 少ない（すぐ上限に達する） 大幅に増加
エラーの頻度 503・429エラーが頻発 ほぼ発生しない
コードの変更 — 不要（同じAPIキーのまま）
費用 無料 使用量に応じた従量課金

有料プランへの切り替え手順

切り替えに必要なもの クレジットカードまたはデビットカード（Google Payも可）。GASプロジェクトに紐づいたGoogleアカウント。
  • 1
    Google Cloud コンソールを開く
    ブラウザで console.cloud.google.com にアクセスします。GASプロジェクトに紐づいているGoogleアカウントでログインしてください。
  • 2
    プロジェクトを選択する
    画面上部のプロジェクト名をクリックして、Crossに紐づいているGoogle Cloudプロジェクトを選択します。
  • 3
    「お支払い」メニューを開く
    左メニューから「お支払い」を選択し、「請求先アカウントをリンク」をクリックします。
  • 4
    請求先アカウントを作成する
    「請求先アカウントを作成」をクリックして、カード情報を入力します。名前・住所・カード番号を登録してください。
  • 5
    完了
    登録完了後、すぐに有料プランが適用されます。APIキーもコードも変更不要です。そのままCrossを使い続けられます。
切り替え後にやること 特別な作業はありません。同じURLでCrossを開き、同じAPIキーで引き続き利用できます。

請求額の目安と上限設定について

Gemini APIは従量課金制です。Crossの通常の使い方（1日数十回程度の生成）では月数百円程度の費用になります。

念のため予算アラートを設定しておくと安心です。Google Cloudの「お支払い」→「予算とアラート」から設定できます。例えば月1,000円を超えたら通知が来るよう設定しておきましょう。

TEXTモードの使い方

TEXT MODE

TEXTモードはX（旧Twitter）への投稿文を生成するメイン機能です。キャラクター・ジャンル・トーンを選ぶだけで、投稿文が自動生成されます。

操作手順

  • 1
    「TEXT」タブを選択
    画面上部のタブで「TEXT」を選択します（起動時はTEXTがデフォルトです）。
  • 2
    キャラクターを選択
    「TAKUYA」または「MAYU」のボタンをタップします。投稿の目的やターゲットに合わせて選んでください。
  • 3
    ジャンルを選択
    「基礎知識 / リスク管理 / 資金管理 / メンタル・心理 / Q&A / 失敗談 / 用語解説 / 時事・市場」から選択します。
  • 4
    トーンを選択
    「教育的・解説 / 共感的・寄り添う / 振り返り・体験談 / 警告・注意喚起 / 励まし / 問いかけ」から選択します。
  • 5
    メモ入力（任意）
    伝えたいキーワードや内容のヒントを自由入力できます。空白のまま生成することも可能です。
  • 6
    サイズを選択
    「140字（短文）」または「800字（長文）」を選択します。
  • 7
    「GENERATE」をクリック
    数秒で投稿文が生成されます。生成後は内容を確認してから使用してください。

IMAGE PROMPTについて

投稿文の生成後に「IMAGE PROMPT を生成」ボタンが表示されます。クリックすると、その投稿文の内容に合った画像生成プロンプトが英語で自動作成されます。

IMAGE PROMPTは必要な時だけ使用 毎回使う必要はありません。投稿に画像を付けたい場合のみクリックしてください。

CHARTモードの使い方

CHART MODE

CHARTモードはFXチャートのスクリーンショットをアップロードすると、初心者向けの解説文をAIが自動生成する機能です。

操作手順

  • 1
    「CHART」タブを選択
    画面上部のタブで「CHART」を選択します。
  • 2
    キャラクターを選択
    「TAKUYA」または「MAYU」を選択します。キャラクターによって解説文のトーンが変わります。
  • 3
    「TAP TO UPLOAD」をタップ
    チャートのスクリーンショット画像を選択してアップロードします。
  • 4
    「GENERATE」をクリック
    AIがチャートを解析して、初心者にわかりやすい解説文を生成します。
  • 5
    免責文言を確認する
    生成結果の末尾に「AIによる参考解説です。」という免責文言が自動で挿入されていることを確認してください。

NG表現チェックについて

NG CHECK

Crossには生成結果の品質を保つためのガードレールが設けられています。生成文に問題のある表現が含まれている場合、画面に警告が表示されます。

警告が出るキーワード

NGキーワード 理由
必ず / 絶対 / 確実に 断定的な表現は投資助言に該当する可能性がある
損しない 元本保証・損失なしの誤解を与える表現
爆益 / 楽して / 一発 過度な期待を煽る表現として不適切

警告が出たときの対応

NG警告 — 表示イメージ
GENERATED TEXT
このトレード手法を身につければ、絶対に利益を出せるようになります...
NG表現が含まれています：「絶対に」— 再生成するか手動で修正してください
  • 1
    再生成する
    「GENERATE」ボタンをもう一度クリックして別の文章を生成します。
  • 2
    手動で修正する
    生成されたテキストをコピーして、NGキーワード部分を別の表現に書き換えてから使用します。

AIが自動で避けている内容

以下の内容はプロンプトレベルでAIに禁止されており、生成文には含まれません。

禁止内容
断定的な投資助言（「ここで買うべき」「必ず上がる」など）
相場の方向性の予測
他のトレーダー・手法・ツールへの批判や比較
専門用語の多用（自動的に平易な日本語に変換）
ハッシュタグの使用
最終確認は必ず人間が行う AIの出力には誤りが含まれる場合があります。生成されたテキストは必ず内容を確認してから投稿してください。

トラブル対応

TROUBLE

Crossを使っていてエラーや表示の問題が発生した場合の対処法をまとめています。

503 Geminiサーバーエラー
Gemini APIが過負荷状態です。1〜2分待ってから再度「GENERATE」をクリックしてください。繰り返す場合はGeminiの有料プランへの切り替えをご検討ください。
429 リクエスト制限超過
リクエストが多すぎて上限に達した状態です。無料プランの場合は有料プランへの切り替えが有効です。有料プランでも連続して大量送信するとまれに出ることがあります。少し間をあけてから再試行してください。
APIキーエラー（401 / 403）
APIキーが無効または期限切れの可能性があります。「API KEY」ボタンからキーを再入力してください。Google AI Studioでキーが有効かどうか確認してみてください。
スマートフォンで画像が読み込めない
古いURLを開いている可能性があります。GASエディタの「デプロイを管理」から最新のURLを確認し、そちらにアクセスし直してください。
文字が小さい / 表示がおかしい
ブラウザのキャッシュが原因の場合があります。ブラウザのキャッシュをクリアしてから再度アクセスしてください。スマートフォンの場合はブラウザのメニューから「閲覧データを削除」で対応できます。
生成が始まらない / ボタンを押しても反応しない
APIキーが未登録の可能性があります。右上の「API KEY」ボタンからキーを入力してSAVEしてください。ブラウザを変えた場合もキーの再入力が必要です。
上記で解決しない場合 ツールの担当者（制作者）にエラーの内容・画面のスクリーンショット・発生した時刻を共有してください。
