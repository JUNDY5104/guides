Palmier Proとは何か

Palmier Pro（パルミエ プロ）は、AIのために作られた動画エディタです。YCombinator S24バッチ出身のスタートアップ「Palmier Inc.」が開発し、2026年にオープンソースとして公開しました。

開発背景 RunwayやHiggsfield等のWeb生成ツールとPremiereを行き来する煩雑なワークフロー（生成→ダウンロード→インポート→再編集のループ）を解消するために開発されました。動画エディタを「単一の情報源」とし、スクリプト・生成・編集をすべて同一プロジェクト内で完結させることを目指しています。
  • 対応OS macOS 26（Tahoe）以降のみ対応
  • 対応ハードウェア Apple Silicon（M1以降）専用。Intel Mac・Windows・Linuxでは動作しない
  • 開発言語 Swift製ネイティブアプリ（AVFoundation + Metal使用）
  • ライセンス エディタ本体・MCPサーバーはGPLv3のオープンソース。AI生成処理部分のみクローズド
  • アカウント エディタ・MCP使用にアカウント登録不要
  • 公式サイト palmier.io（GitHub: palmier-io/palmier-pro）
注意 インターネット上でPalmier Proに関する情報（AI生成のPDFを含む）には不正確な内容が含まれる場合があります。本解説書は公式サイト（palmier.io）・公式ドキュメント（palmier.io/docs）・公式GitHub（github.com/palmier-io/palmier-pro）のみを情報源としています。

S2

無料でできること

Palmier Proは「エディタ本体とMCPは無料、AI生成機能はクレジット制」というシンプルな構造です。アカウント登録なしで以下の機能をすぐに使えます。

▶

動画の読み込みと編集

自分で用意した素材をインポートしてタイムラインに並べ、クリップのトリム・分割・並び替え・調整ができます。

▶

AI生成クリップの再調整

タイムライン上のAI生成クリップをクリックして、プロンプトを微調整して再生成できます（再生成自体はクレジット消費）。

▶

エクスポート

MP4（H.264 / H.265 / ProRes）と、Premiere Pro・DaVinci Resolve向けNLE XML形式でのエクスポートが無料です。

▶

MCPサーバー

Claude Desktop・Cursor・Claude Code・Codexなど外部エージェントとのMCP接続が完全無料で利用できます。

▶

エージェントによるクリップ編集

MCP経由でエージェントがクリップのトリム・分割・並び替え・調整を実行できます（AI素材の新規生成は除く）。

▶

内蔵チャット（BYOK）

自分のAnthropicのAPIキーを持ち込む「BYOK」方式なら、内蔵のPalmier Chatを追加費用なしで使えます（APIの利用料は別途発生）。

整理すると 「自分の素材を使った編集全般」と「外部エージェントへの編集依頼」は無料の範囲内です。「AIによる新しい素材の生成」はすべてクレジットが必要です。

S3

AI生成機能（有料クレジット）

有料プランのクレジットを使うと、タイムラインを離れることなく動画・画像・音声をその場で生成してプロジェクトに組み込めます。

対応AIモデル（公式GitHubに明記されているもの） Seedance・Kling・Nano Banana Pro の3モデルが確認されています。※ネット上で流通している「Veo 3.1」「Grok Imagine」の対応は公式情報では確認できていません。

タイムライン上でのAI生成フロー

1

メディアパネルでモデルを選択

左ペインのメディアパネルでモデルを選び、生成したい内容のプロンプトを入力します。

2

解像度・秒数・アスペクト比を設定

動画生成の場合は解像度・長さ・アスペクト比を設定できます。最初と最後のフレームを指定して、クリップの始点・終点を固定することも可能です。

3

参照画像の追加（任意）

スタイルや被写体の一貫性を保ちたい場合は参照画像を追加できます。

4

タイムラインに自動配置

生成されたクリップはそのままプロジェクトのライブラリに追加され、タイムラインに配置できます。

5

プロンプトを微調整して再生成

AI生成クリップはダブルクリックで元のプロンプト・フレーム・参照画像を確認できます。プロンプトを変えてバリエーション生成も可能です（再生成のたびにクレジット消費）。

内蔵チャット（Palmier Chat）からも生成可能 自然言語で「このシーンにBロールを追加して」と指示すると、チャットがアセットを生成してタイムラインに配置します。@マークで特定の画像を参照しながら指示することもできます。内蔵チャットはBYOK（自前のAnthropicのAPIキー）またはサブスクリプションが必要です。

S4

AIエージェントとのMCP連携

Palmier ProにはMCP（Model Context Protocol）サーバーが内蔵されており、Claude Desktop・Claude Code・Cursor・Codexなど外部のAIエージェントから直接タイムラインを操作できます。MCP機能は完全無料です。

エージェントからできること プロジェクト全体のコンテキストを把握した上で、画像・動画・音声の生成とタイムラインへの配置、クリップのトリム・分割・並び替え・調整、AI生成クリップのプロンプト再調整と再生成が可能です。

接続手順

1

Palmier Proを起動する

アプリが起動すると自動的にhttp://127.0.0.1:19789/mcpでHTTP形式のMCPサーバーが公開されます。設定から有効・無効を切り替えられます。

2

接続手順を確認する

アプリ内のHelp → MCP Instructionsを開くと、各ツール向けの接続手順と1クリックインストールボタンが表示されます。

3

エージェントに指示を出す

接続が完了したら、エージェントのチャットから自然言語で編集指示を出せます。エージェントはタイムラインの構造を読み取りながら作業します。

MCP接続先の設定ファイル例（Cursor） {"mcpServers": {"palmier-pro": {"type": "http","url": "http://127.0.0.1:19789/mcp"}}} Claude Desktopへの接続は「Help → MCP Instructions → Install in Claude Desktop」から1クリックで完了します。
注意 MCPはローカル通信のため、Palmier Proをバックグラウンドで起動したままの状態が必要です。また、AI素材を新規生成する指示はクレジットを消費します。

S6

エクスポートと外部連携

Palmier Proで編集した内容は以下の形式でエクスポートできます。エクスポートは常に無料です。

▶

MP4（H.264 / H.265 / ProRes）

一般的な動画形式でエクスポートできます。SNS投稿・納品など用途に合わせて選択してください。

▶

NLE XML形式

Adobe Premiere ProやDaVinci Resolveにインポートできる形式です。カット位置やクリップリンクを保持したまま移行できます。

推奨ワークフロー例 Palmier ProでAIを活用したラフカット・素材生成を行い、カラーグレーディングや高度な音響編集はPremiere ProやDaVinci Resolveに引き継ぐという使い方が公式で案内されています。
CapCutへのインポートについて ネット上にはCapCut（PC版）へのXMLインポートが可能という情報がありますが、公式ドキュメント・GitHubいずれにもCapCutへの対応は記載されていません。公式に連携が確認されているのはPremiere ProとDaVinci Resolveのみです。
